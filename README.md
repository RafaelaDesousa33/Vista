# Vista

Projeto de um site moderno voltado para o mercado imobiliário, desenvolvido com **HTML, CSS e JavaScript**. O objetivo é apresentar imóveis de forma visual, organizada e atrativa, proporcionando uma experiência agradável e intuitiva para os usuários.

## Sobre o projeto

O **Vista** é um projeto de portfólio desenvolvido para simular uma plataforma imobiliária moderna.

A proposta do projeto é criar uma interface que valorize a apresentação dos imóveis, facilitando a visualização das propriedades e das informações importantes para os usuários. O design foi pensado com foco em organização, responsividade e experiência do usuário.

## Funcionalidades

* Apresentação de imóveis disponíveis
* Exibição de imóveis em destaque
* Informações sobre as propriedades
* Navegação entre as seções do site
* Interface moderna e intuitiva
* Layout responsivo para diferentes dispositivos
* Área de contato
* Design voltado para o mercado imobiliário

## Tecnologias utilizadas

* **HTML5** — Estrutura da aplicação
* **CSS3** — Estilização e responsividade
* **JavaScript** — Interatividade e funcionalidades da interface
* **Font Awesome** — Ícones utilizados na interface

1. Clone este repositório:

```bash

```

2. Acesse a pasta do projeto:

```bash
cd Vista
```

3. Abra o arquivo `index.html` no navegador.
